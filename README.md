# Starbridge tip

Builds of [Starbridge](https://github.com/T0mSIlver/starbridge)'s macOS app from every change to
main that touches it, signed with its Developer ID and notarized. The `tip` release holds only the
newest build; each build replaces its files.

These builds are untested beyond CI. For releases, see
[Starbridge's releases](https://github.com/T0mSIlver/starbridge/releases). A Mac app set to the Tip
channel in Settings → Updates updates from here.

This repository is written by Starbridge's
[desktop workflow](https://github.com/T0mSIlver/starbridge/blob/main/.github/workflows/desktop.yml).
Report problems in [Starbridge's issues](https://github.com/T0mSIlver/starbridge/issues).
